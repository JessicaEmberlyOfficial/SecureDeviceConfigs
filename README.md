## Suggestions
I recommend you to use [AliasVault](https://droidify.app/app/?id=net.aliasvault.app)'s 256 length password generator with all options enabled for generating passwords for apps like, OwnDroid, AppLock, etc. Also use a 20+ length password for biometrics—other apps that can help secure your device is, [SecureScreen](https://droidify.app/app/?id=com.securescreen.app), [Sentry](https://droidify.app/app/?id=me.lucky.sentry), [Duress](https://droidify.app/app/?id=me.lucky.duress), [Wasted](https://droidify.app/app/?id=me.lucky.wasted), [Oblivion](https://droidify.app/app/?id=net.oblivion.wipe), [AppLock](https://droidify.app/app/?id=dev.pranav.applock)
